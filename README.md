# Restaurant Pro — Démo mobile

Version statique destinée à être montrée sur téléphone.

Fonctions de démonstration :
- plan de salle ;
- produits et TVA ;
- commande ;
- lignes de séparation manuelles ;
- envoi Cuisine / Bar / Dessert ;
- séparation de note ;
- transfert de table ;
- paiement simulé ;
- ticket client ;
- sauvegarde locale dans le navigateur.

Cette version n'est pas une caisse de production et n'utilise ni Render ni PostgreSQL.
Elle peut être publiée facilement sur GitHub Pages.
